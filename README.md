Expense Tracker is an iOS application built using SwiftUI and SwiftData that allows users to record, view, and manage their daily expenses efficiently. The app focuses on clean architecture, simplicity, and real-time UI updates with minimal boilerplate code.

Features

Add new expense records with relevant details

View a list of all recorded expenses

Delete expenses with swipe actions

Automatic UI updates on data changes

Lightweight and beginner-friendly implementation

Tech Stack

Language: Swift

UI Framework: SwiftUI

Persistence: SwiftData

Architecture: MVVM

Platform: iOS

Key Highlights

Uses @Model with SwiftData for type-safe local data persistence

Seamless integration between SwiftData and SwiftUI for reactive UI updates
